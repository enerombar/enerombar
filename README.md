## Proyectos destacados

### [Compresión de imágenes con K-Means](https://github.com/enerombar/Compresion_Kmeans)
K-Means implementado desde cero con NumPy y aplicado a reducir los colores de una imagen. Con 32 colores y PNG indexado, el tamaño baja entre un 81 % y un 89 % según la foto. Incluye un notebook que explica el algoritmo paso a paso y un script de línea de comandos.

`Python` `NumPy` `Pillow`

### [Servicio de predicción de churn](https://github.com/enerombar/prediccion-churn)
Proyecto de ML de principio a fin sobre el dataset de Telco: pipeline de entrenamiento configurable por YAML, API de inferencia con validación de entrada, tests y CI. La regresión logística (0,842 de ROC-AUC en test) supera al gradient boosting y queda como modelo por defecto.

`Python` `scikit-learn` `FastAPI` `pytest` `Docker` `GitHub Actions`
